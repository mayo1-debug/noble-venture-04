Comptage des visites

Pour savoir ce qui fonctionne, la page compte des événements anonymes comme « page consultée », « paiement commencé » et « paiement terminé ». Chaque événement ajoute 1 à un compteur chez Abacus (abacus.jasoncameron.dev), un service de comptage gratuit qui peut être exploité hors de l'UE. La requête ne contient que le nom de l'événement. Comme toute requête web, elle atteint le service depuis votre adresse IP ; nous ne recevons jamais votre adresse IP et ne créons aucun profil. Rien n'est enregistré sur votre appareil pour le comptage et aucun cookie n'est utilisé. Base légale : art. 6, par. 1, point f) du RGPD, notre intérêt légitime à savoir comment le site est utilisé.

Ce qui est enregistré sur votre appareil

Uniquement ce dont le service que vous avez demandé a besoin (article 25, par. 2, n° 2 TDDDG), dans le stockage local de votre navigateur :
fc_unlock: votre déblocage et votre numéro de commande PayPal, pour que la version payante reste débloquée.
fc_lang: la langue que vous avez choisie.
noble_exclude, uniquement dans le navigateur de l'exploitant, pour que ses visites ne soient pas comptées.

Paiements

Lorsque vous ouvrez l'étape de paiement, le script PayPal se charge depuis paypal.com. PayPal traite votre paiement en tant que responsable indépendant selon sa propre politique de confidentialité. Nous recevons votre numéro de commande, le montant et les données du payeur que PayPal transmet aux vendeurs (nom, adresse e-mail, pays). Base légale : art. 6, par. 1, point b) du RGPD (exécution du contrat) et point c) (droit fiscal). Nous conservons les justificatifs de paiement 10 ans, comme l'exige le droit fiscal allemand (article 147 AO).

E-mail et assistance

Si vous nous écrivez, nous utilisons votre message et votre numéro de commande uniquement pour vous répondre. Base légale : art. 6, par. 1, point b) du RGPD pour les questions liées à un achat, sinon point f). Nous supprimons les messages d'assistance après 2 ans, sauf si le droit fiscal impose une conservation plus longue.
