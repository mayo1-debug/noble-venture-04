Red and pink DMC floss colors

FlossChart's DMC table has 74 red and pink colors. This page lists all of them with the DMC number, the name and an approximate screen color, from the lightest (DMC 819, Baby Pink Light) to the darkest (DMC 814, Garnet Dark).

How the list is made: a color is on this page when its DMC name contains one of these words: "red", "garnet", "cranberry", "coral", "salmon", "raspberry", "alizarin", "melon", "geranium", "pink", "rose", "carnation", "cyclamen", "blossom", "shrimp". Names are what DMC calls the color, so a few colors show up in two families (for example a "Blue Green" is on the green page and the blue page). Lightness is measured as CIELAB L*, the same color math the FlossChart converter uses.

The biggest red and pink color groups

Many DMC colors come in runs of one name from very light to very dark. In this family the biggest runs are: Dusty Rose (10), Shell Pink (7), Cranberry (6), Salmon (6), Rose (5). The Dusty Rose run, light to dark, is: Dusty Rose Ultra Very Light (963), Dusty Rose Very Light (151), Dusty Rose Medium Very Light (3716), Dusty Rose Light (3354), Dusty Rose (3733), Dusty Rose Medium (962), Dusty Rose Dark (961), Dusty Rose Very Dark (3731), Dusty Rose Ultra Dark (3350), Dusty Rose Ultra Very Dark (150).

The closest look-alikes in this family, by the same color difference: DMC 894 and DMC 776 (difference 0,9); DMC 3706 and DMC 604 (difference 1,5); DMC 3833 and DMC 3733 (difference 1,5). On screen these are hard to tell apart, so check the real thread before you swap one for another.
