Cross-stitch size chart: stitches to cm and inches

How big will a cross-stitch be? Divide the stitches by the fabric count to get inches, then multiply by 2,54 for centimeters. The table below has done it for common pattern widths on 11, 14, 16 and 18 count Aida, the four fabrics FlossChart offers.

The same numbers work for the height: look up the number of rows instead of the number of columns. Leave extra fabric around the design for framing; how much is your choice, so it is not in the table.

Questions

How do I work out the finished size of a cross-stitch?

Divide the number of stitches by the fabric count. That gives inches. Multiply by 2,54 for centimeters. 140 stitches on 14 count Aida is 140 / 14 = 10 inches, or 25,4 cm.

Does a higher Aida count make the design smaller?

Yes. The count is the number of stitches per inch, so more stitches per inch means a smaller finished piece. 100 stitches are 23,1 cm on 11 count and 14,1 cm on 18 count.

How many stitches wide should a pattern be?

That depends on the size you want and the fabric. Pick the finished width, multiply the inches by the fabric count, and set that as the width in stitches. FlossChart allows 20 to 500 stitches; charts up to 40 x 40 print free.

Get the size for your own photo

In FlossChart you set the width in stitches with a slider (20 to 500, in steps of 5). The height follows the shape of your photo, and the finished size for the fabric you pick updates as you move the slider. The printed cover page lists the size on all four fabrics.
